# @dsh-anime/client-character

[English](README.md) | 中文

Electron 二次元外壳的角色领域。宿主端注册 `ui-anime` 设置命名空间，并从 `$DSH_HOME/anime/packs` 提供 Character Pack v1 素材；浏览器端拥有可观察角色状态、系统语音、不封顶的默契度及去重账本、角色包实时刷新、「常规设置」配置项，以及每条助手消息的朗读、暂停、继续和停止操作。

角色包 manifest 会声明画布、固定预览和背景、身体与口型层、表情和效果映射、带动画与 fallback 的全部八个状态、待机动作，以及中英文默契解锁。无效 manifest、重复 id、路径穿越、缺失素材与不支持的图像格式都会被拒绝；原创内置 Lumi 分层素材始终作为回退角色可用。缺少许可证的有效角色包只能在本机使用。

## 模型体验

无，因为角色状态只观察已有浏览器投影、消息评价变化和设置；语音清理和好感度都不会进入仅追加会话日志或模型上下文。

#### KV Cache 影响

无；任何角色操作都不会改变模型历史。

## 已知限制与待办事项

- 语音使用浏览器已安装的语音合成声音，因此可用声音和发音效果取决于 Windows 安装环境。
- 角色包验证会检查元数据和文件范围，但不会核实角色包作者所声明许可证在法律上的准确性。
- 内置 Lumi 图像是原创矢量占位角色，后续可以用正式美术包替换，无需修改运行时代码。
