# @dsh-anime/client-shell

[English](README.md) | 中文

沉浸式场景／工作界面以优先级 `-100` 注册到 `layout.frame`。它只安排官方侧栏、会话、详情和浮层的渲染回调，不拥有这些区域的业务状态。卸载本包后，会恢复优先级 `0` 的上游 `AppFrame`，并保留已经挂载的布局与会话状态。

该框架会把官方窄屏状态同步到共享布局存储，在宽度小于 1100 像素时显示 56 像素侧栏并采用工作布局，遵循系统和用户的减少动态效果偏好，并使用角色包声明的 Web Animations。44 像素自定义标题栏只在 Electron preload API 存在时显示；普通浏览器仍保留场景／工作模式控制，但不会显示桌面窗口按钮。

## 模型体验

无，因为本包只会从浏览器会话快照推导角色表现，不会增加、修改或持久化模型可见内容。

#### KV Cache 影响

无；模型请求不会发生变化。

## 已知限制与待办事项

- 外壳使用静态状态图片与 CSS 动效，不使用 Live2D、骨骼动画、视频或 3D 渲染。
- 标题栏只在 Windows 上完成验收，其它平台专属的窗口交互尚未验证。
